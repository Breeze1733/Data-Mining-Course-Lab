# 景区游览指南的程序性知识挖掘

本实验以黄山、九寨沟和颐和园的官方指南及游客游记为语料，完成数据清洗、实体识别、路线解析、共指消解、条件建议抽取、知识图谱和旅游规划 Agent。

## 提交材料

按任务书提交 `task1/report.docx` 至 `task7/report.docx` 和根目录的 [实验总结反思](实验总结反思.docx)，共八份报告。随报告附上代码、结构化结果和下表中的证据，保留目录结构以便核查。**Git 跟踪的文件组成提交树**。打包时使用 Git 跟踪清单，或从包含本次整理的提交执行 `git archive`，不要直接压缩整个工作区。

| 实验 | 提交证据与结果 |
|---|---|
| 1 采集与清洗 | `task1/data/raw/dataset_raw.jsonl` 的原始语料、[数据工作簿](task1/data/collected/scenic_guide_dataset.xlsx)和 `task1/data/processed/` 的清洗结果。三景区共 267 条保留记录（近重复已物理去重），均达到每景区至少 1 条官方路线和 5 篇游记的目标。官方路线分支见 `task1/data/raw/official_routes.jsonl`。 |
| 2 实体识别 | `task2/resources/` 和 `task2/output/exp2/` 的领域词典、带位置实体、人工抽检、词频图及优化前后对比。句级抽样评测精确率 85.2%，召回率 69.7%。 |
| 3 路线结构 | `task3/output/` 的格式分析、步骤、时间层级和官方与游客对比。46 条官方分支中 39 条有序，34 条拆成多个路线步骤，另 5 条是含多个景点的单步骤段落；叙述片段与路线步骤分开存放。对比使用 225 条游客路线。 |
| 4 共指消解 | `task4/output/` 的代词位置、候选和消解结果，以及 180 例冻结人工标注。总体准确率 63.3%，留出集 58.3%。报告列出正确与失败例。 |
| 5 条件建议 | `task5/output/` 的原句、映射表 Excel/JSON、分组图和抽查。候选 1,060 对，过滤 279 对非游览建议（住宿设施/外卖/菜单/广告/吐槽/抒情）后去重保留 770 条映射（392 条带显式条件）。52 条分层抽检严格 65.4%、宽松 76.9%（边界切分 10、非游览主题 5、误抽 3），漏抽排查 20 句中 3 句真漏抽。 |
| 6 知识图谱 | `task6/output/` 的节点和边 CSV、GraphML、静态概览、完整分景区交互图及核验结果。517 节点、2,636 边，保留先后顺序的双向证据，6/6 条经典顺序核验通过。 |
| 7 旅游规划 Agent | [单次在线实测](task7/output/online/)保存同一批次的 14 场景汇总、结构化行程和全部轨迹（LangGraph ReAct，模型自主调用图谱工具每场景 9–19 次）。14/14 达到当批断言，14 场景混合意图解析、13 场景模型润色；报告记录首轮 8/14 的失败归因与修复。 |
| 总结反思 | 三类主要失败的归因与改进，及以句子级景区归属为突破点的学期研究方案。 |

`task1/` 至 `task7/` 的源码和必要资源、`requirements.txt` 随包提供。任务之间通过各 `output/` 产物通信，不跨文件夹 import 代码；实体与别名规则由 task2 的 `entity_dictionary.json` 发布。冻结标注、关键中间证据及实验 2 的优化前后对比属于评分材料。
