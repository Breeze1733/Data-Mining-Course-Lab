# 云端与本地代码的审核及合并说明

审核日期：2026年10月29日。依据仓库内《数据挖掘》探索性实验任务书及评分细则，比较本地提交 `1365788` 与云端提交 `51a7798`。原作者分别为本地 Breeze1733、云端实验2 Gene；云端实验1报告来自 lws666 的提交。评价对象是实现与证据，不据此评价作者能力。

## 结论与合并取舍

采用模块整合。云端实验2在配置、schema、时间规则、输入校验和泛化方面更完整；本地在领域词典、跨景区标记、完整实验链及报告交付方面更完整。整合保留两者能力，并修复对照和全量检查中发现的缺陷。

| 任务书考核重点 | 本地实现 | 云端实现 | 整合处理 |
|---|---|---|---|
| 实验1的数据与来源 | 303条组装记录，271条主语料，22份官方文档和46个分支，已配套下游 | 可处理collected字段，保留标签与元数据，有幂等及CSV检查；报告中的25份/57个分支不能由当前数据复现 | 主语料不变；保留独立采集清洗器，默认写processed_collected，报告使用可核验口径 |
| 实验2实体定义与实现 | 人工整理的领域词典及周边地点；保留in_scenic，适配实验3至7 | 规则分模块、细粒度时间、配置来源、未知景区低置信兜底 | 保留领域种子与兼容接口，共享时间、交通规则及公共别名表 |
| 质量检查 | 历史54个实体抽检和下游评估 | 偏移、schema、重复、重叠、manifest、67项原始测试 | 全量核验主接口21,089个实体，另保留配置接口QC；严格对齐旧标签，新增实体不冒充已人工评估 |
| 迭代与可视化 | baseline/refined、词云、报告和完整后续实验 | iter1/iter2、分来源统计、QC模板和运行清单 | 保留两种接口，明确统计范围；重建图表和所有受影响下游产物 |
| 可复现性与交付 | 实验1至7及总结反思完整 | 可配置实体流水线更通用 | 提供离线主链入口，修复PowerShell参数传递、环境回退、输入适配和README大小写冲突 |

两套实验1清洗器的输入不是同一批记录，不能用271与150的数量直接比较清洗质量。配置实体接口处理249篇游客文本、22份官方文档和46条分支，共317条分层输入；其analysis排除支撑文档，不能将其实体数与271条主语料直接比较。

## 地点名称一致性

`task2/resources/poi_aliases.csv`是公共别名来源，`common/entity_identity.py`统一供实体、路线和图谱读取。路线比较和图谱均把显示简称映回同一景区的已知canonical，避免官方“玉屏”和游客“玉屏景区”被当作两个地点。

- 明确统一耕织图景区/耕织图、树正磨坊/树正磨房、诺日朗服务中心名称变体。
- 检查别名多目标、环映射以及显示简称冲突；不以相似字符串自动合并对象。
- 同名实体以景区命名空间区分；宾馆与区域不作为同一对象。明确的“宾馆附近”只提供共指上下文线索。
- 7条别名和489处官方路线POI引用全部对齐，未发现缺身份属性的图谱节点。详见`naming_validation.json`。

后续可以将稳定地点ID作为真正的关联键，名称仅作显示与检索；本轮仍保持下游既有canonical接口，没有声称已经完成稳定地点ID迁移。

## 效果与评估边界

- 主接口：271条文本、21,089个实体；偏移错误、重复区间、交叉重叠均为0。
- 历史54例中53例与当前文档、类型、原文和区间完全一致，可继承历史判定；“西海”现属于“西海小火车”完整交通名称，原标签留作历史记录。未将53例的继承结果称为新抽样精度。
- 共指消解沿用原120例金标准，标签未改变，先核验位置再评分，准确率保持42.5%。同时修复报告生成器曾将部分景区名错配算对、导致v1正文与题注不一致的问题，统一v1为27.5%。
- 路线、图谱、Agent已重跑；6项图谱事实、三个景区连通性和无孤立节点检查通过。Agent六个离线场景通过，未声称验证真实LLM调用效果。
- 配置接口QC通过结构检查；其人工复核仍为模板状态，不宣称已有人工准确率。
- 113项单元测试通过：实验1为28项，实验2为78项，实验3为2项，公共命名模块5项。具体指标及输入哈希见`metrics.json`。
